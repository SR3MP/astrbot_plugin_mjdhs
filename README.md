# 雀魂赛事管理插件 (astrbot_plugin_mjdhs)

在 QQ 群内用 `%` 前缀指令管理雀魂赛事：绑定赛事、查询大厅与排名、管理选手、开赛与控制对局，并自动播报对局开始与结束。

## 鸣谢

本项目基于 [senjugakuen/mjdhs](https://github.com/senjugakuen/mjdhs)（MIT 许可证）构建。

## 指令一览

| 类别 | 指令 | 功能 | 权限 |
|------|------|------|------|
| 系统 | `%帮助` | 查看指令说明 | 任意 |
| 系统 | `%查看配置` | 查看账号（密码打码）、管理员白名单、管理模式 | 管理员 |
| 系统 | `%配置 账号 xxx 密码 xxx` | 修改雀魂账号密码 | 管理员 |
| 系统 | `%配置 管理 123 456` | 设置管理员白名单（`清空` 移除全部） | 管理员 |
| 系统 | `%配置 模式 any/strict` | 切换管理模式 | 管理员 |
| 系统 | `%重置配置` | 重置账号与权限配置 | 管理员 |
| 绑定 | `%绑定 赛事id` | 将本群与赛事绑定 | 管理员 |
| 绑定 | `%解绑` | 解绑本群赛事 | 管理员 |
| 查询 | `%规则` | 查看赛事规则 | 任意 |
| 查询 | `%名单` | 查看参赛选手名单 | 任意 |
| 查询 | `%公告` | 查看赛事公告 | 任意 |
| 查询 | `%大厅` | 查看进行中对局的选手与实时分数、准备中玩家 | 任意 |
| 查询 | `%待机` | 查看准备中玩家 | 任意 |
| 查询 | `%排名 [条数]` | 查看当前排名（昵称 / 总分 / 对局数），默认列出全部（最多 50 条） | 任意 |
| 查询 | `%对局记录 [条数]` / `%记录` | 查看最近对局结果（牌谱、时间、各选手点数），默认 5 条 | 任意 |
| 选手 | `%添加 雀魂id1,雀魂id2` | 添加选手 | 管理员 |
| 选手 | `%删除 雀魂id` | 删除选手 | 管理员 |
| 对局 | `%开赛 [列表]` | 开赛（缺省用准备中玩家，详见「开赛语法」） | 管理员 |
| 对局 | `%暂停 [对局编号]` | 暂停对局（缺省取当前对局） | 管理员 |
| 对局 | `%恢复 [对局编号]` | 恢复对局 | 管理员 |
| 对局 | `%终止 [对局编号]` | 终止对局 | 管理员 |
| 播报 | `%播报 开` / `%播报 关` | 打开 / 关闭本群对局播报；不带参数为切换 | 任意 |

对局编号即 `%大厅` 中每局显示的编号，可用于 `%暂停` / `%恢复` / `%终止`。

## 功能示例

### `%大厅`

显示进行中每局的选手、实时分数、当前场次与对局编号，以及准备中玩家：

```
[对局中(2局)]
甲 22600 / 乙 19400 / 电脑 33400 / 丁 24600
  南3局 1本 | 261113-9a23c56e-646c-419b-817d-b1eb598ae108
戊 44500 / 己 34300 / 庚 11600 / 辛 9600
  南4局 2本 | 261113-b0094b9d-8094-4778-83e0-2a055ca33986
[准备中(2人)]
yutsiu,加滑艾拉陈
```

### `%排名`

显示当前累计排名，默认列出全部选手（最多 50 条）；可用 `%排名 10` 只显示前 10 名：

```
[排名(3人)]
姓名 / 总分 / 对局数
1. 甲 / 52300 / 4
2. 乙 / 31000 / 4
3. 戊 / 1200 / 2
```

### `%对局记录`

按对局结束播报的格式展示最近若干局；可用 `%对局记录 10` 调整条数（最多 20 条）：

```
[对局记录(最近1条)]
对局结束: /?paipu=261113-cccc
22:26:40 - 23:26:40
甲 42100
乙 30500
戊 18600
己 8800
```

### 对局播报

绑定赛事的群会自动推送对局开始与结束消息，每个群可用 `%播报` 单独开关：

```
对局开始: 甲,乙,电脑,电脑

对局结束: /?paipu=261113-cccc
22:26:40 - 23:26:40
甲 42100
乙 30500
戊 18600
己 8800
```

## 开赛语法

`%开赛` 缺省时自动使用「准备中」的玩家，不足人数自动补电脑：

| 写法 | 含义 |
|------|------|
| `%开赛` | 用准备中玩家开赛 |
| `%开赛 id1,id2` | 指定玩家雀魂 ID |
| `%开赛 昵称1,昵称2` | 按昵称匹配玩家 |
| `%开赛 列表\|\|标签` | 为对局设置标签 |
| `%开赛 !列表` | 固定座位（不随机交换） |
| `%开赛 玩家 500,玩家2 500` | 指定各玩家初始点数 |

## 管理员权限

绑定 / 解绑、配置、添加 / 删除选手、开赛、暂停 / 恢复 / 终止都需要管理员权限；查询、对局播报开关所有群成员均可使用。

设置管理员白名单（立即生效，无需重启）：

```
%配置 管理 12345 67890     # 添加多个可管理的人
%配置 管理 清空            # 清空白名单
%配置 模式 strict          # 只认白名单
%配置 模式 any             # 白名单、群管理、全局管理员任一满足即可
```

> OneBot（aiocqhttp / Go-CQ）填 **QQ 号**，QQ 官方平台只能填 **OPENID**；`%查看配置` 可随时确认当前白名单与管理模式。

## 安装与使用

1. 将 `astrbot_plugin_mjdhs` 目录放入 AstrBot 的 `data/plugins/`。
2. 在 AstrBot 插件设置页填写「雀魂账号」「雀魂密码」（需有赛事管理权限），或由管理员在群内发 `%配置 账号 xxx 密码 xxx`；其余配置项按需调整。
3. 管理员在目标群发 `%绑定 赛事id` 完成绑定。
4. 重启 AstrBot，群内发 `%帮助` 查看指令。

## 常见问题

- 提示「尚未绑定赛事」：由管理员先发 `%绑定 赛事id`。
- 提示「需要管理员权限」：把用户加入白名单，或确认其群管理身份。
- 雀魂登录失败：用 `%查看配置` 确认账号密码后重新配置。
- 添加选手失败：确认填写的是**雀魂账号 ID** 而不是昵称。
- 没有对局播报：发 `%播报 开` 打开本群播报，并确认插件设置页的「对局播报」已开启。

## 注意

- 请遵守雀魂用户协议，勿滥用自动化功能。
- 账号密码保存在 AstrBot 插件配置页，请确保部署环境安全，不要提交到公开仓库。
