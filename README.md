# 雀魂赛事管理插件 (astrbot_plugin_mjdhs)

通过 QQ 群管理**雀魂（Mahjong Soul）赛事后台** 的 AstrBot 插件。v1.5.0 为**纯 Python REST API** 实现，不再依赖 Node.js / mjsoul / 被墙的 WebSocket 网关。

## 功能

在 QQ 群内通过指令管理雀魂赛事。群通过 `%绑定 赛事id` 与雀魂赛事绑定（一条赛事只对应一个群）。

| 类别 | 指令 | 说明 | 权限 |
|------|------|------|------|
| 系统 | `%帮助` | 查看本说明 | 任意 |
| 系统 | `%查看配置` | 查看账号（密码打码）、管理员白名单、管理模式 | 管理员 |
| 系统 | `%配置 账号 xxx 密码 xxx` | 修改雀魂账号密码 | 管理员 |
| 系统 | `%配置 管理 123 456` | 设置管理员白名单（可多个；`清空` 移除全部） | 管理员 |
| 系统 | `%配置 模式 any/strict` | 切换管理模式（见下） | 管理员 |
| 系统 | `%重置配置` | 重置账号与权限配置 | 管理员 |
| 绑定 | `%绑定 赛事id` | 将 QQ 群与赛事绑定（如 `%绑定 123456`） | 管理员 |
| 绑定 | `%解绑` | 解绑当前群赛事 | 管理员 |
| 查询 | `%规则` | 查看赛事规则 | 任意 |
| 查询 | `%名单` | 查看参赛选手名单 | 任意 |
| 查询 | `%公告` | 查看赛事公告 | 任意 |
| 查询 | `%大厅` | 查看对局中/准备中玩家 | 任意 |
| 查询 | `%待机` | 查看准备中玩家 | 任意 |
| 查询 | `%排名` | 查看当前排名/对局记录 | 任意 |
| 选手 | `%添加 雀魂id1,雀魂id2` | 添加选手（多个用逗号分隔） | 管理员 |
| 选手 | `%删除 雀魂id` | 删除选手（多个用逗号分隔） | 管理员 |
| 对局 | `%开赛 [列表]` | 开赛（缺省用准备中玩家；支持指定 ID/昵称、标签、固定座位、点数，见下） | 管理员 |
| 对局 | `%暂停` | 暂停当前对局（可指定对局 UUID） | 管理员 |
| 对局 | `%恢复` | 恢复对局（可指定对局 UUID） | 管理员 |
| 对局 | `%终止` | 终止对局（可指定对局 UUID） | 管理员 |

## 管理员权限

所有写操作（绑定/解绑、配置、添加/删除选手、开赛/暂停/恢复/终止）都需要管理员权限。判断顺序：

1. **白名单（`admin_ids`）**：最高优先级。命中即管理员。
2. **管理模式 `admin_mode`**：
   - `any`（默认）：群管理（仅 OneBot 平台）或 AstrBot 全局 `admins_id` 也算管理员；
   - `strict`：**只认白名单**，白名单为空则任何人都不是管理员（适合先收紧再放行）。

### 如何设置白名单

两种方式（二选一即可）：

- 在 **AstrBot 插件配置页**（本插件设置 → 管理员白名单）直接填写并保存，保存后即时加载；
- 或用管理员账号在群内发指令（**立即生效，无需重启**）：

```
%配置 管理 12345 67890     # 添加多个可管理的人
%配置 管理 清空            # 清空白名单
%配置 模式 strict          # 切到"只认白名单"
%配置 模式 any             # 切回默认宽松模式
```

> ⚠️ **平台 ID 差异**：
> - **OneBot v11（aiocqhttp / Go-CQ）**：`admin_ids` 填 **QQ 号**，且群主/群管理自动算管理员（`any` 模式下）。
> - **QQ 官方 API（qq_official / qq_official_webhook）**：拿不到 QQ 号，只能填用户的 **OPENID**（可从 AstrBot 日志的消息 `sender_id` 获取）；没有群角色信息，所以**必须**靠白名单或 AstrBot 全局 `admins_id` 判断管理员。

`%查看配置` 会显示当前账号（密码打码）、白名单和管理模式，可随时确认。

## 架构

```
QQ群 → AstrBot 插件 (main.py + mjsoul_client.py)
           ↓ 直接 HTTP（HTTPS + Authorization 认证）
雀魂赛事 REST API (https://contest-gate-202411.maj-soul.com)
```

**优点：**
- ✅ 纯 Python，无需 Node.js / mjsoul / WebSocket
- ✅ 直接调用雀魂官方 HTTP API，自动绕过被墙的旧网关（gateway-v2.maj-soul.net）
- ✅ 认证简单：`Authorization: Majsoul <token>`，登录密码以 `HMAC-SHA256(password, "lailai")` 加密后发送

## 安装

### 1. 放置插件

将 `astrbot_plugin_mjdhs` 目录放入 AstrBot 的 `data/plugins/` 下。

### 2. 配置雀魂账号

配置优先级：**AstrBot 插件配置页** > 群内 `%配置` 指令 > 旧 `mjsoul_config.json`。

- **方式 A（推荐）：在 AstrBot 插件设置里修改**

  1. 打开 AstrBot 管理面板，进入 **插件管理** → 找到「雀魂赛事管理」→ 打开它的**设置**页；
  2. 填写并保存，相关字段如下（**保存后即时生效，无需重启**）：

     | 字段 | 说明 |
     |------|------|
     | 雀魂账号 | 用于登录赛事管理后台的雀魂账号（需有赛事管理权限） |
     | 雀魂密码 | 对应账号的密码，明文存储，请确保部署环境安全；修改后下一条指令会用新账号重新登录 |
     | 管理员白名单 | 可用本插件管理指令的用户标识。OneBot(aiocqhttp/Go-CQ) 填 QQ 号；qq_official 只能填 openid。留空则回到原有逻辑（群管理/全局管理员） |
     | 管理模式 | `白名单+群管理/全局`（any，默认）或 `仅白名单`（strict） |
     | 对局播报 | 是否自动轮询推送对局开始/结束消息（默认开启） |
     | 播报轮询间隔(秒) | 检查进行中对局与已完赛牌谱的时间间隔，建议 5~30 秒 |

  > 只需填写前两项（**雀魂账号、雀魂密码**）即可正常使用，其余字段按需调整。

- **方式 B**：群内用管理员账号发指令
  ```
  %配置 账号 你的账号 密码 你的密码
  ```
  配置会保存到插件配置页（配置页不可用时回退写入 `mjsoul_config.json`），重启仍有效，下次直接自动登录。

- **方式 C**：直接在插件目录新建 `mjsoul_config.json`
  ```json
  {
    "account": "你的账号",
    "password": "你的密码"
  }
  ```
  旧版沿用此文件；升级后首次加载会自动把其中的账号/密码/白名单迁移到插件配置页。

### 3. 绑定赛事

首次使用，由管理员在目标群里发：
```
%绑定 123456
```
（赛事 ID 在雀魂赛事页面查看）

### 4. 重启 AstrBot

重启后插件生效。群内发 `%帮助` 查看指令。

## 开赛语法

`%开赛` 缺省时自动使用「准备中」的玩家（不足 4 人自动补电脑 AI）：

| 写法 | 含义 |
|------|------|
| `%开赛` | 用准备中玩家开赛 |
| `%开赛 id1,id2` | 指定玩家雀魂 ID |
| `%开赛 昵称1,昵称2` | 按昵称匹配玩家 |
| `%开赛 列表\|\|标签` | 为对局设置标签 |
| `%开赛 !列表` | 固定座位（不随机交换） |
| `%开赛 玩家 500,玩家2 500` | 指定各玩家初始点数 |

## 使用前提

1. 雀魂账号已开通赛事管理权限
2. 群内由管理员 `%绑定 赛事id`
3. 写操作需管理员权限（白名单 / OneBot 群管理 / AstrBot admins_id）

## 技术说明

- **API 地址**：`https://contest-gate-202411.maj-soul.com`
- **登录**：`POST /api/login`，请求体含账号、`lailai` 密码、`HMAC-SHA256(password, "lailai")` 加密密码，返回 `authorization` token
- **认证**：后续请求头 `authorization: Majsoul <token>`
- **对局控制**：`pause_contest_running_game` 端点通过 `resume` 参数区分（`1`=暂停，`2`=恢复）
- **赛事 ID**：通过 `fetch_contest_list` 返回的 `unique_id` 与用户输入的 `contest_id` 映射
- 已支持端点：赛事列表/详情/赛季、选手名单、准备中、对局中、对局记录、公告、账号搜索、添加/删除选手、开赛、对局控制

## 故障排查

- 提示"尚未绑定赛事"：由管理员先用 `%绑定 赛事id`
- 提示"需要管理员权限"：检查是否在白名单（`%配置 管理`），或 OneBot 群管理；`strict` 模式下必须配好白名单
- 提示"绑定/解绑需要管理员权限"：同上，绑定/解绑也需要管理员
- 雀魂登录失败：用 `%查看配置` 确认账号密码，可在 AstrBot 插件配置页或群内 `%配置 账号 xxx 密码 xxx` 重新配置
- 添加选手失败：检查提供的是否为正确的**雀魂账号 ID**（不是昵称）

## 注意

- 请遵守雀魂用户协议，勿滥用自动化功能
- 账号密码以明文存储在 `mjsoul_config.json`（已加入 `.gitignore`，请勿提交到公开仓库）
- 代码中的默认配置（`DEFAULT_CONFIG`）为占位符，不含真实凭据；请按「安装 → 配置雀魂账号」的**方式 A**（AstrBot 插件设置）或 `%配置` 指令写入实际账号密码，配置后可用 `%查看配置` 确认
- qq_official 平台看不到 QQ 号，白名单只能填 openid；如需按 QQ 号管理请使用 OneBot 接入
